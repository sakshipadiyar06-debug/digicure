DigiCure

An unhackable hardware password vault for your ESP32-S3. Provision firmware, upload updates, and manage credentials securely via Web Serial.

Web Serial is not supported in this browser. Please open DigiCure in Chrome, Edge, Opera, or Brave.

Initialize your ESP32-S3 hardware with the optimized MicroPython runtime. This prepares the partition table for encrypted credential key storage.

Your browser doesn't support Web Serial. Web Serial is only allowed over HTTPS or localhost.
2

Upload DigiCure Application

Upload the main DigiCure script (main.py) to your connected hardware device. Existing encrypted credentials will remain untouched.

Connect directly over Web Serial to interact with your encrypted DigiCure hardware vault in real-time.
